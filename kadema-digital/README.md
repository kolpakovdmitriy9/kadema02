# Kadema Digital — прототип главной (первый экран + «Опыт» + «Как это работает»)

Открыть `index.html` в браузере, сборка не нужна. Макет 1440px, поля 60px; на узких окнах страница целиком масштабируется.

## Поведение по аннотациям
- **Шапка из двух частей.** При загрузке видны обе части и строка «Калькулятор бюджета». При скролле вниз шапка целиком прячется, при скролле вверх возвращается уже без калькулятора. Калькулятор выезжает при наведении на правую часть.
- **«Как это работает».** Тёмная карточка начинает расти, как только блок заходит в экран, и раскрывается на весь экран примерно к моменту закрепления. Внутри — бесконечная «куча» картинок: новая карточка шлёпается сверху (крупнее ×1.07 с доворотом 2°, оседает за 140 мс), карточки ложатся россыпью с наклоном ±2–7°, нижние заранее незаметно уменьшаются и уходят под кучу (пружина без рывков), колода идёт по кругу. Работает, только пока блок на экране. Текст остаётся по центру. Длина раскрытия задаётся высотой `.how` в `styles.css`, параметры кучи — константы `PILE_MAX`, `SINK_*`, `SPREAD_*`, `DROP_*`, `RHYTHM_FRAMES` в `script.js`.

## Картинки
Сейчас везде заглушки. Положите файлы в `images/`, и они встанут поверх заглушек без правок кода:
`hero.jpg`, `case-main.jpg`, `case-mobile.jpg`, `stack-1.jpg` … `stack-12.jpg` (карточки кучи, по порядку появления).

## Шрифт
Vela Sans подключён из `fonts/` (400, 500, 600). Onest оставлен запасным шрифтом.
