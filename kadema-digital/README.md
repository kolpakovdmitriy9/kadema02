# Kadema Digital — прототип главной (первый экран + «Опыт» + «Как это работает»)

Открыть `index.html` в браузере, сборка не нужна. Макет 1440px, поля 60px; страница целиком масштабируется ровно по ширине окна без полосы прокрутки — на узких экранах уменьшается, на широких увеличивается.

## Поведение по аннотациям
- **Шапка из двух частей.** При загрузке видны обе части и строка «Калькулятор бюджета». При скролле вниз шапка целиком прячется, при скролле вверх возвращается уже без калькулятора. Калькулятор выезжает при наведении на правую часть.
- **«Как это работает».** Пока блок заходит в экран, тёмная карточка с лёгким параллаксом догоняет заголовок над собой (едет вверх на ~20% быстрее скролла) и понемногу расширяется во все стороны (+80px в ширину, +40px в высоту, нарастает к концу захода). Как только она встаёт по центру экрана (секция закрепилась), карточка резко раскрывается на весь экран — переход 0.8 с, `cubic-bezier(0.16, 1, 0.3, 1)`: почти сразу набирает скорость и долго доводится. При скролле обратно так же сворачивается. Внутри — бесконечная «куча» картинок: новая карточка шлёпается сверху (крупнее ×1.07 с доворотом 2°, оседает за 140 мс), карточки ложатся россыпью с наклоном ±2–7°, нижние заранее незаметно уменьшаются и уходят под кучу (пружина без рывков), колода идёт по кругу. Работает, только пока блок на экране. Куча вписывается в место между плашкой и текстом (`.how__media`, масштаб `--k`), поэтому картинки никогда не заходят на текст. Сколько блок держится закреплённым — высота `.how` в `styles.css`, параметры кучи — константы `PILE_MAX`, `SINK_*`, `SPREAD_*`, `DROP_*`, `RHYTHM_FRAMES` в `script.js`.
- **«Команда + ИИ».** Сразу под раскрытой карточкой продолжается тёмный блок. Название этапа в скобках и две колонки («Команда» / «Искусственный интеллект») закрепляются по центру экрана, этапы переключаются скроллом — на каждый нужна заметная прокрутка (`--duo-step` в `styles.css`, сейчас 520px). Команда и название этапа меняются сразу; ИИ сначала «думает» (точки, мигающий маркер), потом быстро печатает текст по буквам. Пока текст ИИ не напечатан, прокрутка дальше текущего этапа заблокирована. Текст «Объединяем скорость…» из карточки выше не уезжает: между ним и названием этапа всегда ровно 140px: оба блока едут, закрепляются и уходят вместе. Прогресс-бар по центру встаёт в одно из 4 положений (переезд — плавным переходом) — видно, сколько этапов осталось. Пунктов 4; тексты — массив `DUO_STEPS` в `script.js` (при изменении количества поправьте `--duo-steps` в `styles.css`). 
- **«Задачи, которые решает сайт».** Квадрат с фото — со скруглением «как в iOS» (Corner smoothing 100%, как в Figma; контур строит `squircle()` в `script.js`). Пока блок подъезжает, квадрат по скроллу растёт до своего размера (×0.6 → ×1). Блок не останавливается — всё едет вместе со скроллом. Когда верх блока подходит к верху экрана, полуавтоматически (по времени, 0.9 с, сильный ease-out — как раскрытие тёмной карточки) всё тёмное полотно (сцена, этапы и карточка «Как это работает» выше) перекрашивается в `#FFF4F8`, текст и линии — в чёрный; синхронно внутри фото проступает размытая маска — сначала тонкой рамкой по форме квадрата, потом вырез уменьшается и скругляется до круга 184px. Дальше по ходу скролла появляется значок «2». Ниже — сетка из 6 задач. Отметки срабатывания (`T_LIGHT`, `T_BADGE`) — в `script.js`.
- **Белая часть** выезжает из-под розового блока с параллаксом.
  - **«Выберите формат под задачу».** Два плавающих «облака» с текстом двигаются со своей скоростью. Табы «Быстрый запуск / Сайты для бизнеса / Для застройщиков» переключают описание слева и список тарифов справа (плавная смена). Своей прокрутки у списка нет: если тарифы не помещаются, список плавно подъезжает вместе со скроллом страницы. По клику тариф раскрывается (поворачивается только стрелка): описание и что входит — пункты в 2–3 колонки. Данные — массив `PRICE` в `script.js`.
  - **«Этапы разработки».** Блок закрепляется; 5 шагов (`STEPS`). На следующий шаг — только после «усилия» (накопленной прокрутки колесом, `STEP_EFFORT`), а анимация шага доигрывает сама (`STEP_MS`): фото листается по вертикали, пагинация справа, текст проявляется снизу через прозрачность. Фото шагов — `images/step-1.jpg` … `step-5.jpg` (пока заглушки).
  - **«Экономика проекта».** Цветок закрепляется по центру экрана и уменьшается, если не помещается по высоте. 8 лепестков крутятся по часовой стрелке; когда лепесток встаёт на 12 часов, меняется фраза в скобках справа (`ECO`). Картинки лепестков — `images/eco-1.jpg` … `eco-8.jpg` (пока заглушки).

## Картинки
Фон первого экрана — `images/hero.webp`. Остальные картинки пока заглушки: положите файлы в `images/`, и они встанут поверх заглушек без правок кода:
`case-main.jpg`, `case-mobile.jpg`, `stack-1.jpg` … `stack-12.jpg` (карточки кучи, по порядку появления), `duo.jpg` (картинка в круглом окне блока «Команда + ИИ»).

## Шрифт
Vela Sans подключён из `fonts/` (400, 500, 600). Onest оставлен запасным шрифтом.
