# Kadema Digital — прототип главной (первый экран + «Опыт» + «Как это работает»)

Открыть `index.html` в браузере, сборка не нужна. Макет 1440px, поля 60px; на узких окнах страница целиком масштабируется.

## Поведение по аннотациям
- **Шапка из двух частей.** При загрузке видны обе части и строка «Калькулятор бюджета». При скролле вниз шапка целиком прячется, при скролле вверх возвращается уже без калькулятора. Калькулятор выезжает при наведении на правую часть.
- **«Как это работает».** Тёмная карточка начинает расти, как только блок заходит в экран, и раскрывается на весь экран примерно к моменту закрепления. Картинки собраны в стопку, которая перелистывается скроллом: карточки из хвоста сверху съезжают вниз и накрывают главную, при обратном скролле улетают вверх. Текст остаётся по центру. Длина анимации задаётся высотой `.how` в `styles.css`.

## Картинки
Сейчас везде заглушки. Положите файлы в `images/`, и они встанут поверх заглушек без правок кода:
`hero.jpg`, `case-main.jpg`, `case-mobile.jpg`, `stack-1.jpg` … `stack-12.jpg` (карточки стопки, по порядку появления).

## Шрифт
Vela Sans подключён из `fonts/` (400, 500, 600). Onest оставлен запасным шрифтом.
