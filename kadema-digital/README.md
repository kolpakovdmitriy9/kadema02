# Kadema Digital — прототип главной (первый экран + «Опыт» + «Как это работает»)

Открыть `index.html` в браузере, сборка не нужна. Макет 1440px, поля 60px; страница целиком масштабируется ровно по ширине окна без полосы прокрутки — на узких экранах уменьшается, на широких увеличивается.

## Поведение по аннотациям
- **Шапка из двух частей.** При загрузке видны обе части и строка «Калькулятор бюджета». При скролле вниз шапка целиком прячется, при скролле вверх возвращается уже без калькулятора. Калькулятор выезжает при наведении на правую часть.
- **«Как это работает».** Пока блок заходит в экран, тёмная карточка с лёгким параллаксом догоняет заголовок над собой (едет вверх на ~20% быстрее скролла) и понемногу расширяется во все стороны (+80px в ширину, +40px в высоту, нарастает к концу захода). Как только она встаёт по центру экрана (секция закрепилась), карточка резко раскрывается на весь экран — переход 0.8 с, `cubic-bezier(0.16, 1, 0.3, 1)`: почти сразу набирает скорость и долго доводится. При скролле обратно так же сворачивается. Внутри — бесконечная «куча» картинок: новая карточка шлёпается сверху (крупнее ×1.07 с доворотом 2°, оседает за 140 мс), карточки ложатся россыпью с наклоном ±2–7°, нижние заранее незаметно уменьшаются и уходят под кучу (пружина без рывков), колода идёт по кругу. Работает, только пока блок на экране. Куча вписывается в место между плашкой и текстом (`.how__media`, масштаб `--k`), поэтому картинки никогда не заходят на текст. Сколько блок держится закреплённым — высота `.how` в `styles.css`, параметры кучи — константы `PILE_MAX`, `SINK_*`, `SPREAD_*`, `DROP_*`, `RHYTHM_FRAMES` в `script.js`.
- **«Команда + ИИ».** Сразу под раскрытой карточкой продолжается тёмный блок. Название этапа в скобках и две колонки («Команда» / «Искусственный интеллект») едут вместе со страницей, без закрепления; этапы переключаются по ходу, пока блок проезжает через экран. Команда и название этапа меняются сразу; ИИ сначала «думает», потом быстро печатает текст. Между абзацем «Объединяем скорость…» и названием этапа всегда 140px. Прогресс-бар по центру встаёт в одно из 4 положений (переезд — плавным переходом) — видно, сколько этапов осталось. Пунктов 4; тексты — массив `DUO_STEPS` в `script.js` (при изменении количества поправьте `--duo-steps` в `styles.css`). 
- **«Задачи, которые решает сайт».** Квадрат с фото — со скруглением «как в iOS» (Corner smoothing 100%, как в Figma; контур строит `squircle()` в `script.js`). Пока блок подъезжает, квадрат по скроллу растёт до своего размера (×0.6 → ×1). Когда верх блока закрепляется, полуавтоматически (по времени, 0.9 с, сильный ease-out — как раскрытие тёмной карточки) всё тёмное полотно (сцена, этапы и карточка «Как это работает» выше) перекрашивается в `#FFF4F8`, текст и линии — в чёрный; синхронно внутри фото проступает размытая маска — сначала тонкой рамкой по форме квадрата, потом вырез уменьшается и скругляется до круга 184px. Дальше по скроллу появляется значок «2». Ниже — сетка из 6 задач. Длина сцены — `--tasks-scene` в `styles.css`, порог значка — в `onTasks()`.

## Картинки
Фон первого экрана — `images/hero.webp`. Остальные картинки пока заглушки: положите файлы в `images/`, и они встанут поверх заглушек без правок кода:
`case-main.jpg`, `case-mobile.jpg`, `stack-1.jpg` … `stack-12.jpg` (карточки кучи, по порядку появления), `duo.jpg` (картинка в круглом окне блока «Команда + ИИ»).
