# Kadema UI

Набор стилей и компонентов для страниц Kadema Digital. Он собран из главной (`kadema-digital/`): шрифт Vela Sans, фирменный розовый `#F50F72`, чёрное, ночное и светло-розовое полотно, таблицы-аккордеоны, метки в уголках, стеклянная шапка.

- Витрина компонентов: `ui/index.html` (на Pages — `/kadema02/ui/`)
- Пример страницы: `direct/index.html` — «Контекстная реклама в Яндекс Директ»

## Блоки 2.0
Композиции вместо сеток одинаковых карточек (подробно — в витрине, раздел «Блоки 2.0»):
- `.k-say` — крупная фраза со вставками: цифры, пилюли, аватары, мини-картинки
- `.k-focus` — список с фокусом: строка раскрывается, справа меняется плитка
- `.k-hacc` — горизонтальный аккордеон: активная колонка раскрывается
- `.k-pick` — облако пилюль с панелью подробностей
- `.k-flow` — поток: узлы на линии, по линии бегут точки
- `.k-car` — карусель/дорожка со стрелками, прогрессом и счётчиком; `.k-stepcard` — шаг дорожки
- `.k-flip` — переключатель «как бывает / как делаем мы»
- `.k-pile` — стопка карточек, ложатся друг на друга при прокрутке
- `.k-orbit` — роли вокруг центра
- `.k-checks` — чек-лист со счётчиком
- `.k-widget` — стеклянный виджет-отчёт (цифры помечаются «пример»)

## Файлы
| Файл | Что внутри |
|---|---|
| `kadema-ui.css` | токены (цвет, шрифт, радиусы, сетка) и все компоненты с префиксом `k-` |
| `kadema-ui.js` | табы, аккордеоны, шапка (прячется при прокрутке, темнеет над светлым), меню, бегущие ленты, окно с формой, проверка форм, спрайт иконок |
| `partials/` | общие куски: `header.html`, `modal.html`, `footer.html`, `logo.html` |
| `pages/*.src.html` | исходники страниц со вставками `{{head:…}}`, `{{header}}`, `{{modal}}`, `{{footer}}` |
| `build.py` | собирает страницы из исходников: `python3 ui/build.py` |

Шрифт, видео для логотипа и картинка первого экрана берутся из `kadema-digital/` — копировать их не нужно.

## Новая страница
1. Скопируйте `pages/direct.src.html` в `pages/<имя>.src.html`.
2. В первой строке укажите, куда собрать: `<!-- out: ../../<папка>/index.html -->`.
3. Замените содержимое между шапкой и подвалом. Используйте компоненты из витрины.
4. Запустите `python3 ui/build.py`.

## Иконки
`<svg class="k-icon"><use href="#k-i-arrow"/></svg>`. Список иконок — объект `I` в начале `kadema-ui.js`, новые добавляются туда же.

## Поведение через data-атрибуты
- `data-k-tabs` — табы (`role="tab"` + `aria-controls`)
- `data-k-accordion` / `data-k-accordion="multi"` — таблица-аккордеон
- `data-k-modal` — открыть окно с формой
- `data-k-form` — форма: проверяет телефон и согласие (прототип, заявки никуда не отправляются)
- `data-k-tabs="hover"`, `data-k-item`, `data-k-keep` — табы с наведением и классом `.is-on`
- `data-k-car`, `data-k-flip`, `data-k-checks` — карусель, переключатель, чек-лист
- `data-header="light"` — секция со светлым фоном, шапка над ней темнеет

## Отличие от главной
Главная свёрстана под макет 1440 и масштабируется целиком. Набор сделан резиновым: размеры шрифтов идут через `clamp()`, а сетки перестраиваются на 1100, 900, 760 и 560 px.
